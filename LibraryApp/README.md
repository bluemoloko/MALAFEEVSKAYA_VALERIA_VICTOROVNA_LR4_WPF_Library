# Библиотека — WPF-приложение для бронирования книг
Данная программа представляет собой приложение для работы с библиотекой. 
Написано на C# (WPF, .NET Framework) с использованием Entity Framework и MS SQL Server.
Пользователи могут просматривать каталог книг, искать их по названию и автору, регистрироваться и бронировать книги. 
Библиотекарь видит все брони и управляет ими: выдаёт книги, принимает возврат, удаляет брони. 
Доступ к страницам зависит от роли: гость, читатель или библиотекарь.

## Установка

1. Клонировать репозиторий по ссылке из Git
2. Создать базу данных. Открыть SQL Server Management, 
выполнить скрипт `libraryScript.sql`
Будет создана база `Library` с таблицами:
`Authors`
`Books`
`Readers`
`Librarians`
`Loans`
`Users`
3. Проверить строку подключения в файле `App.config` 
4. Открыть решение `LibraryApp.sln` восстановите NuGet-пакет Entity Framework и запустить отладку пронекта

## Использование

### Авторизация и регистрация

При запуске открывается страница входа. 
Доступны три варианта
Войти. Необходимо ввести логин и пароль.
Регистрация. Необходимо создать аккаунт читателя. Для регистрации библиотекаря нужен код `LIB2026`.
Продолжить как гость. Необходимо открыть каталог без входа.

### Роли и возможности
Гость:
- Просмотр каталога, поиск и фильтр по автор
Читатель:
- Просмотр каталога, поиск и фильтр по автор
- Бронирование книги
Библиотекарь:
- Просмотр каталога, поиск и фильтр по автору
- Просмотр всех броней
- Выдача, прием возврата, удаление броней

Кнопки меню, недоступные текущей роли, скрыты.

### Поиск книг

Для поиска определенной книги на странице "Каталог книг необходимо" ввести часть названия или имени автора в поле поиска. 

### Бронирование книги

1. Войти как читатель
2. В каталоге выбрать книгу и нажать "Забронировать выбранную" либо открыть страницу "Забронировать" и выбрать книгу из выладающего списка книг.
3. Нажать "Забронировать". Книге будет присвоен новый статус "ЗАбронировано" и она станет недоступной для брони другим читателям.
4. Брони авторизированного читателя можно посмотреть на странице "Мои брони". Бронь со статусом «Забронировано» можно отменить.

### Управление бронями 

На странице "Все брони" необходимо выбрать одну запись и нажать одну из предоставленных кнопок: "Выдать", "Принять возврат", "Просрочено", "Удалить".
После возврата книга снова становится доступной для бронирования.
